# 📌 등록 절차

## 1. 영문 등록정보 추가

Play Console → 앱 선택 → 좌측 **성장(Grow)** 섹션 → **기본 스토어 등록정보(Main store listing)** → 페이지 상단 **번역 관리(Manage translations)** → **언어 추가 또는 삭제** → `영어(미국) – en-US` 추가 → 위 문구 입력 → 저장 후 **검토를 위해 제출**.

- 기본 언어(한국어)는 그대로 두고 en-US를 **추가**하는 것 — 기본 언어를 바꾸는 게 아닙니다.
- 등록정보 변경은 **심사 대상**입니다(보통 몇 시간~며칠). 앱 업데이트 심사와는 별개로 돌아가니, 업로드 키 승인과 무관하게 지금 진행 가능합니다.

## 2. 자동 번역, 두 가지가 다릅니다

| | 무엇 | 어떻게 |
|---|---|---|
| **A. 자동 표시 번역** | 등록 안 한 언어로 방문한 유저에게 Google이 즉석 번역본을 보여줌 | **아무 작업 불필요**. 이미 동작 중 |
| **B. 무료 기계 번역** | 내 등록정보를 최대 29개 언어로 기계번역해 **실제 등록** | 번역 관리 → 기계 번역 선택. 무료, 몇 분 |

**이번엔 A로 충분합니다.** B는 권하지 않습니다 — 이유는 위 ⚠️ 절: UI가 한국어뿐인 앱을 스페인어·포르투갈어 등으로 정식 등록하면 앱을 쓸 수 없는 유저 유입 → 저평점 위험만 커집니다. 한글 학습 수요가 실재하는 **일본어·중국어(번체)** 정도만 나중에 손번역으로 선별 추가하는 게 낫습니다.

- 스크린샷·피처그래픽은 **한국어판 그대로 재사용 가능**(en-US 등록정보에서 따로 안 올리면 기본 언어 것이 표시됨). 앱 화면이 실제로 한국어라 오히려 정직한 노출입니다.
